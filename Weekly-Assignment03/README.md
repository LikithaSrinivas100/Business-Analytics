# Assignment 03: Operational Sales Performance Dashboard

## Project Overview
Replaced a retail firm's fragmented manual spreadsheet tracking system with a live, highly interactive corporate dashboard tracking sales, revenue, volume metrics, and categorical product growth vectors.

## Core Analytics Fabricated
* **Executive Metrics:** High-level KPI indicators highlighting total enterprise gross revenue (16M) and warehouse dispatch totals (618).
* **Temporal Volatility Tracking:** Continuous line trend mapping operational waves over a daily calendar timeline.
* **Product & Spatial Segmentation:** Clustered bar charts capturing key product line drivers (*Eco Ultra Laptop*) alongside branch volume distributions (*Delhi, Bengaluru, Mumbai*).
* **Global Interaction Slicer:** Implemented an interactive top-row horizontal slice panel sorted by customer location nodes to allow instant dashboard cross-filtering.
