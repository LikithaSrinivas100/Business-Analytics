# Assignment 02: Advanced Relational Data Modeling

## Project Overview
Focused heavily on data architecture optimization and schema manipulation to convert raw corporate transaction tables into an enterprise-ready analytics infrastructure.

## Core Implementation Steps
1. **Schema Refinement:** Separated flat transactional structures into distinct dimension and fact entities.
2. **Referential Integrity Validation:** Standardized missing indexes, duplicates, and metadata type mismatches.
3. **Model Optmization:** Applied logical entity relationships to enhance query processing and chart execution response times.
